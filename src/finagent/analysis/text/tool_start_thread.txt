단일 분석 작업을 신규 스레드에 위임한다. 스레드는 독립 컨텍스트에서 데이터 도구와 웹 검색을 수행해 완료 시 결과를 보고하며, 호출 즉시 스레드 id만 반환하고 완료를 대기하지 않는다. `kind`는 `macro`(매크로 정밀 분석 보고서), `stock`(종목 정밀 분석 보고서), `etf`(ETF 정밀 분석 보고서), `research`(자유 주제 조사·분석) 중 하나를 지정한다. `macro`, `stock`, `etf`는 표준 분석 가이드와 출력 형식이 내장되어 있으므로 사용자가 추가로 요청한 조건·관점이 있을 때만 `task`를 입력하고 별도 조건이 없으면 생략한다. `research`는 `task`에 작업 지시 전체를 구체적으로 작성한다.
