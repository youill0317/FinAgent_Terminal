작업 하나를 신규 스레드에 위임. 호출 즉시 스레드 id만 반환하고 결과는 대기하지 않음. kind 파라미터는 macro(매크로 분석 보고서), stock(종목 분석 보고서), etf(ETF 분석 보고서), research(그 밖의 조사·분석) 지정. macro, stock, etf는 분석 에이전트 팀(수집 → 강세·약세 토론 → 종합)이 정해진 형식의 보고서를 작성하고 완료 시 보고서 하나로 보고(task 필드에는 추가로 살필 점만 기재). research는 스레드 하나가 독립 컨텍스트에서 데이터 도구 및 웹 검색을 수행하고 완료 시 보고하며, task가 작업 지시의 전부. research에 agent 지정 시 해당 수집 에이전트의 역할과 도구 범위로 수행.
