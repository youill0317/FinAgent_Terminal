웹 검색 및 원문 읽기 도구 사용 가능.

- 입력 문서 내 기재 값 검색 금지. 수치 및 시장 반응은 데이터 도구 우선 조회. 웹 검색 용도: ISM 지표, 공시 밖 실적 내용, 정책 표결·성명서, 뉴스. 데이터 도구 조회에 실패한 값은 웹 검색 가능. 필요 시 공식 원문 조회.
- 단일 실행당 웹 검색 및 원문 읽기 합산 최대 {limit}회 제한.
- 보유 내역 및 거래 기록의 값 검색어 입력 금지.
- 웹에서 가져온 값과 사실을 쓴 문장 끝에 [[web:<URL 또는 도메인>|<기준일 YYYY-MM-DD>]] 첨부. 표기 하나당 출처 하나만 지정. 앞서 웹으로 확인한 값을 다시 쓸 때도 그 문장에 웹 인용을 다시 첨부하고, 지표 인용만 붙이지 말 것.
- 공식 원문 최우선, 확인 사실·기업 전망·외부 컨센서스·AI 추정 구분 기술.
